
# نظام الحملات التسويقية الذكي (Marketing Campaigns Hub)

## الفكرة
وحدة جديدة كاملة داخل لوحة الجمعية تُحوّل بيانات الجمعية (متبرعون، تبرعات، مشاريع، إنجازات، أثر) إلى حملات تسويقية احترافية بقيادة الذكاء الاصطناعي، مع تدريب الموظف خطوة بخطوة من الصفر حتى قياس النتائج.

## المكوّنات الرئيسية

### 1) أكاديمية التسويق (Marketing Academy)
مسار تدريبي تفاعلي للموظف داخل المنصة:
- مقدمة في تسويق الجمعيات الخيرية
- بناء الرسالة التسويقية من رسالة الجمعية ومشاريعها وأثرها
- اختيار الجمهور المستهدف (segments من قاعدة المتبرعين)
- اختيار المنصة المناسبة لكل جمهور (واتساب، SMS، إيميل، تويتر/X، سناب، تيك توك، إنستغرام، يوتيوب، جوجل آدز)
- المحتوى: نص، تصميم، فيديو، موشن جرافيك
- التوقيت والمواسم (رمضان، عشر ذي الحجة، محرم، العام الدراسي، الشتاء، اليوم الوطني…)
- الميزانية والتكاليف
- القياس والتقييم واتخاذ القرار
كل درس ينتهي بـ"طبّق الآن" يفتح الموظف على إنشاء حملة فعلية.

### 2) مولّد الحملات بالذكاء الاصطناعي (AI Campaign Generator)
زر "اقترح حملات" يحلل:
- المشاريع الحالية والمواسم القادمة
- شرائح المتبرعين (كبار/متكررون/منقطعون/سلال متروكة)
- الأثر السابق وأرقام الإنجازات
- النتائج التاريخية للحملات السابقة
ويُخرج 3–5 حملات مرشحة لكل منها:
- الاسم، الفكرة، الجمهور المستهدف، المنصات
- الرسالة الأساسية + 3 زوايا محتوى
- مسودات نصوص (واتساب/SMS/تغريدات/كابشن/سكربت فيديو)
- بريف للتصميم والموشن جرافيك
- جدول نشر مقترح (يوم/ساعة لكل منصة)
- ميزانية تقديرية وتوزيعها
- KPIs متوقعة (وصول، تفاعل، تحويل، تبرعات)

### 3) مساحة الحملة (Campaign Workspace)
صفحة لكل حملة فيها:
- Brief كامل (هدف، جمهور، رسالة، عرض القيمة)
- Content Studio: مولّد نصوص + بريف تصميم/فيديو + رفع الأصول النهائية
- Channel Plan: قنوات + مواعيد + مسؤول + حالة (مسودة/مجدول/منشور)
- Budget Tracker: مخطط vs فعلي
- Checklist تنفيذية (يقترحها AI ويُحوّلها لمهام عبر `smart-task-dispatcher`)
- Live Status: ما الذي تم، ما المتأخر، التنبيهات

### 4) متابعة وتقييم (Performance & Insights)
- لوحة نتائج الحملة: Impressions, Clicks, Conversions, Donations, ROI, CPA
- مقارنة بالحملات السابقة وبالـKPIs المتوقعة
- توصيات AI تلقائية: "أوقف هذا الإعلان"، "ضاعف الميزانية على X"، "أعد توجيه الرسالة لشريحة Y"
- تقرير ختامي PDF/Word جاهز للمشاركة مع الإدارة

### 5) المواسم والتقويم التسويقي
تقويم سنوي مدمج (هجري + ميلادي) فيه:
- المواسم الدينية والوطنية في السعودية
- اقتراح حملة لكل موسم تلقائيًا قبل 30/14/7 يومًا
- تذكير الموظف وتجهيز الـbrief مسبقًا

### 6) ذاكرة التسويق (Marketing Memory)
كل حملة سابقة تتحول إلى تجربة يستفيد منها الـAI:
- ما الذي نجح/فشل
- أفضل الأوقات والمنصات لكل شريحة
- نماذج رسائل أعلى تحويلًا

## الصفحات والمسارات
- `/:slug/internal-dashboard?tab=marketing` — رئيسية الحملات
- `/:slug/marketing/academy` — الأكاديمية
- `/:slug/marketing/calendar` — التقويم الموسمي
- `/:slug/marketing/campaigns` — قائمة الحملات
- `/:slug/marketing/campaigns/new` — إنشاء (يدوي أو بالـAI)
- `/:slug/marketing/campaigns/:id` — مساحة الحملة
- `/:slug/marketing/campaigns/:id/insights` — التقييم والنتائج

## قاعدة البيانات (جداول جديدة)
- `marketing_campaigns` (الحملة + status + dates + budget + audience + AI metadata)
- `marketing_campaign_assets` (نصوص/تصاميم/فيديوهات + bucket)
- `marketing_campaign_channels` (قناة + جدول نشر + حالة + نتائج)
- `marketing_campaign_metrics` (impressions/clicks/conversions/donations زمنيًا)
- `marketing_academy_lessons` + `marketing_academy_progress`
- `marketing_seasonal_events` (تقويم المواسم)
- `marketing_playbook_memory` (دروس من الحملات السابقة للـAI)
كلها مع RLS على `organization_id`.

## Edge Functions (Lovable AI Gateway)
- `marketing-suggest-campaigns` — يحلل بيانات الجمعية ويقترح حملات (gemini-3-flash-preview)
- `marketing-generate-content` — نصوص/كابشن/سكربتات لكل قناة
- `marketing-design-brief` — بريف تصميم/موشن
- `marketing-evaluate-campaign` — تحليل النتائج وتوصيات
- `marketing-seasonal-radar` — يفحص التقويم يوميًا (cron) ويقترح حملات للمواسم القادمة
- جميعها تستخدم `LOVABLE_API_KEY` ولا تتطلب أي مفاتيح من المستخدم.

## التكامل مع الموجود
- `smart-task-dispatcher`: تحويل خطوات الحملة لمهام على الموظفين
- `tasks` table: متابعة تنفيذ الموظف داخل الحملة
- `donors`/`donations`/`projects`: مصدر بيانات الاستهداف
- `Intelligence` (الرؤى): تغذية الحملات بالرؤى المكتشفة

## التنفيذ على مراحل
بسبب الحجم الكبير جدًا (3 جداول رئيسية + 5+ edge functions + 6 صفحات + أكاديمية)، أقترح:

- **مرحلة ١ — الأساس**: جداول DB + صفحة Hub + قائمة الحملات + إنشاء يدوي + AI suggest (`marketing-suggest-campaigns`)
- **مرحلة ٢ — Workspace**: صفحة الحملة الكاملة (Brief + Content Studio + Channel Plan + Budget + ربط بالمهام) + `marketing-generate-content` + `marketing-design-brief`
- **مرحلة ٣ — التقييم**: Metrics + `marketing-evaluate-campaign` + تقرير ختامي + ذاكرة Playbook
- **مرحلة ٤ — التقويم والأكاديمية**: التقويم الموسمي + `marketing-seasonal-radar` (cron) + دروس الأكاديمية التفاعلية

## أسئلة قبل البدء
1. هل أبدأ بالمرحلة ١ مباشرة الآن، أم تريد المراحل الأربع متتابعة في رسائل دون توقف؟
2. هل تريد ربط فعلي بمنصات النشر (Meta/X/TikTok APIs) أم نكتفي بالتخطيط والمتابعة اليدوية لنتائج الموظف يُدخلها بنفسه (الأسرع والأكثر مرونة لأول إصدار)؟
3. الميزانية: هل تتعامل بالريال السعودي فقط؟
