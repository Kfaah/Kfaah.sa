## منظومة المالية الذكية المتكاملة — الإصدار الموسّع

نبني فوق ما تم في الإصدار السابق (جداول `expenses`, `expense_allocations`, `donor_spend_summary`، صفحة الإدارة المالية) ونضيف 5 طبقات ذكية متكاملة.

---

### 1. رفع ملف مصروفات Excel + توزيع تلقائي ذكي

**الواجهة**: زر "📥 استيراد من Excel" في الإدارة المالية → صفحة كاملة فيها:
- منطقة سحب وإفلات لملف `.xlsx` / `.csv`
- قراءة الملف في المتصفح بـ `xlsx` (مكتبة موجودة)
- معاينة جدولية للصفوف قبل الحفظ
- لكل صف: النظام **يقترح تصنيفاً ومشروعاً** عبر edge function `classify-expense-batch` (Lovable AI Gemini Flash) بناءً على وصف الصف وقائمة المشاريع الموجودة في تبرعات الجمعية
- المستخدم يراجع/يعدّل ثم "حفظ الكل" → يُدخَل دفعة واحدة → الـtrigger يوزّعها تلقائياً
- شريط تقدم + تقرير "تم استيراد X مصروف، تعذّر Y"

**الأعمدة المتوقعة**: التاريخ، الوصف، المبلغ، المورد (اختياري)، المشروع/الحملة (اختياري). النظام يطبّع رؤوس الأعمدة عربياً وإنجليزياً.

---

### 2. عتبة "تم صرف كامل تبرعك" للمتبرع (50%)

**القاعدة المُعتمدة**:
- لو `allocated/donated >= 50%` → يُعرض للمتبرع: **"تم صرف كامل تبرعك لصالح [اسم المشروع]"** ✅
- لو أقل من 50% → يُعرض شريط التقدم الفعلي مع رسالة "جارٍ توجيه تبرعك"
- حقل جديد `donor_spend_summary.fully_spent_message` يُحسب تلقائياً

نحدّث:
- `DonorTransparencyView`: يستبدل العمود "نسبة الإنفاق المرئية" بـ Badge أخضر "تم الصرف بالكامل ✓" + اسم المشروع، بدلاً من شريط نسبة
- نضيف عمود "حالة الشفافية" مع نص جاهز يمكن نسخه/إرساله

---

### 3. تقارير المتبرع الجاهزة + خطاب شكر

**زر بجانب كل متبرع** → "📄 إصدار تقرير وخطاب":
- تقرير PDF احترافي (RTL، خط Cairo، شعار الجمعية): إجمالي تبرعاته، توزيعها على المشاريع، تواريخ الصرف، رسالة شكر
- خطاب شكر Word (.docx) قابل للتعديل، باسم المتبرع ومبلغ تبرعه ومشروعه
- تستخدم نفس مكتبات التصدير الموجودة (`exportGrantProposal.ts` كنموذج)
- زر "📤 تصدير دفعة" يُصدر تقارير لكل المتبرعين النشطين دفعة واحدة (zip)

---

### 4. اقتراحات تقارير ذكية بالذكاء الاصطناعي

**Edge Function**: `suggest-finance-reports`:
- يحلّل بيانات الجمعية: المصروفات، التوزيع، المتبرعون، المشاريع
- يقترح 5-8 تقارير قيّمة (مثال: "تقرير شفافية ربعي للمتبرعين الكبار"، "تقرير كفاءة الإنفاق على مشروع X"، "تقرير اتجاه التسويق مقابل العائد")
- لكل اقتراح: عنوان، وصف، الجمهور المستهدف، الفائدة، زر "إنشاء"
- بطاقات أنيقة في تبويب "💡 تقارير ذكية" داخل الإدارة المالية

---

### 5. التكامل مع المحتوى الخارجي (موقع + سوشيال) — إطار قابل للتمدد

**نضيف الآن** (بنية جاهزة، التشغيل الكامل في إصدار لاحق):
- جدول `org_external_sources`: `organization_id`, `kind` (website/twitter/instagram/facebook), `url`, `last_synced_at`, `summary`
- صفحة "🌐 المصادر الخارجية" داخل إعدادات الجمعية: المستخدم يضيف رابط الموقع وحسابات السوشيال
- Edge function `sync-external-source` يستخدم **Firecrawl** (موجود في المشروع) لجلب محتوى الموقع، ويلخّصه بـ AI ويخزّن نتائج في `org_external_insights` (عناوين أخبار، فعاليات، إحصائيات)
- في صفحة "تقارير ذكية"، يُدمج هذا المحتوى تلقائياً عند توليد تقرير: "حسب الموقع، أقامت الجمعية فعالية X في تاريخ Y، وارتبطت بمصروفات بقيمة Z"

**ما يُنفّذ الآن من هذه النقطة**: الجداول + صفحة الإعدادات + edge function لجلب الموقع وتلخيصه (Firecrawl + Gemini). دمج السوشيال (تويتر/إنستجرام يحتاج OAuth أو APIs مدفوعة) → مرحلة لاحقة بعد تأكيد المستخدم على المصادر.

---

### تفاصيل تقنية

- **مكتبات جديدة**: `xlsx` (موجود)، `docx` (موجود)، `jspdf` + `html2canvas` (للتقارير) — نتأكد من توفّرها
- **Edge functions جديدة**: `classify-expense-batch`, `suggest-finance-reports`, `generate-donor-report`, `sync-external-source` — كلها تستخدم Lovable AI (Gemini 3 Flash للسرعة، Gemini 2.5 Pro للتقارير المعقدة)
- **هجرة DB**: `donor_spend_summary` يضيف `fully_spent_message` و `primary_project`؛ جدولان جديدان `org_external_sources` و `org_external_insights`
- **أمان**: كل الجداول الجديدة بـRLS كاملة (قراءة لأعضاء الجمعية، كتابة لمسؤوليها)
- **أداء**: تصنيف Excel بالـAI يتم على دفعات (10 صفوف لكل استدعاء) لتقليل التكلفة

---

### ما يتم في هذا الإصدار (تنفيذ كامل)
1. صفحة استيراد Excel كاملة + edge function للتصنيف
2. منطق "تم صرف كامل تبرعك" في DB + الواجهة
3. تصدير تقرير PDF + خطاب Word لكل متبرع
4. تبويب "تقارير ذكية" مع اقتراحات AI
5. صفحة المصادر الخارجية + edge function تلخيص موقع الجمعية بـFirecrawl

### مرحلة لاحقة (نؤكد قبل البدء)
- مزامنة دورية للمحتوى (cron)
- ربط حسابات السوشيال (تويتر/إنستجرام عبر OAuth)
- توليد تقارير شاملة تدمج البيانات الداخلية + الموقع + السوشيال في PDF واحد ضخم
