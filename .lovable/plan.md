# خطة: تطوير صفحات الأيقونات الثمانية في لوحة التقارير الداخلية

## الفكرة العامة
كل أيقونة من الأيقونات الثمانية الموجودة في تبويب "التقارير" تفتح صفحة تفصيلية مستقلة تحتوي على:
1. **فلتر زمني موحّد**: اليوم، الأمس، الأسبوع الحالي، الأسبوع الماضي، الشهر الحالي، الشهر الماضي، السنة، الكل.
2. **فلاتر خاصة بكل تقرير** (فئات، حالات، مبالغ، مشاريع…).
3. **جدول مفصّل** يعرض لكل سجل (متبرع/حملة/مستقطع…) ما الذي تم تنفيذه: خطاب شكر، تقرير، إهداء، رسالة WhatsApp، فيديو، PDF، تصميم… إلخ.
4. **عمود "الإجراءات المنفذة"** يجمع كل المهام التي أكملها الموظفون لهذا السجل (من جدول `tasks` المرتبط).

## الصفحات المطلوبة
1. **المتبرعون حسب الفئة المالية** — فلتر زمني + فلتر فئة (كبار/متوسط/صغير) + جدول: المتبرع، الفئة، الإجراءات المنفذة (خطاب/تقرير/إهداء/رسائل…)، آخر تواصل.
2. **الحملات** — فلتر زمني + فلتر حالة (نشطة/مكتملة/تحتاج تنشيط/مغلقة/الكل) + أعمدة: تم التنفيذ؟ تم إعداد التقرير؟ تم الإرسال؟ + رفع/عرض ملف التقرير.
3. **التبرعات الفاشلة** — فلتر زمني + نطاق مبلغ (من-إلى) + جدول: المتبرع، المبلغ، التواصل ١، التواصل ٢، النتيجة (أعاد/لم يعد)، نوع المحاولة (SMS/WhatsApp/PDF/فيديو/تصميم…).
4. **السلال المتروكة** — نفس بنية التبرعات الفاشلة.
5. **المستقطعون** — فلتر زمني + فلتر الحالة (مستمر/منقطع/متذبذب) + أيقونتان لكل سجل: "بيانات الاستقطاع" و"التقارير والإجراءات".
6. **المتبرعون المتكررون** — فلتر زمني + جدول: الانتظام، شكر، مشاريع مفضلة، الإجراءات المنفذة.
7. **الإهداءات** — فلتر زمني + جدول: المُهدي، المُهدى إليه، حالة التسليم، آخر إجراء.
8. **متبرعو المشاريع** — فلتر زمني + فلتر مشروع (من قائمة مشاريع المسجر) + جدول: المتبرع، المشروع، التقارير المُسلَّمة، الرسائل المرسلة.

بالإضافة إلى:
- **تحليل ورؤى بالذكاء الاصطناعي** (الأيقونة الموجودة): زر "تشغيل" يولّد رؤى ويُسقطها كمهام على الموظفين عبر `smart-task-dispatcher`.

## مكونات مشتركة (لتفادي التكرار)
- `<UnifiedDateFilter />` — فلتر زمني واحد يُستخدم في كل الصفحات (presets + custom range).
- `<DonorActionsCell />` — خلية تعرض الإجراءات المنفذة على متبرع (badges مع أيقونات: خطاب، تقرير، WhatsApp، PDF، فيديو، إهداء، تصميم).
- `<ReportPageShell />` — هيكل صفحة موحّد (header + filters + table + actions).
- مصدر بيانات الإجراءات: جدول `tasks` (status=completed) مع `metadata.channel` و`metadata.donor_id` و`category`.

## التكامل مع المسجر
لعرض المشاريع في صفحة "متبرعو المشاريع": استخراج المشاريع تلقائيًا من ملفات Excel المرفوعة (الجدول `uploads` / `operational_plans`) وعرضها كقائمة فلتر.

## الـ Routing
صفحات جديدة تحت:
- `/:slug/internal-dashboard/reports/donors-by-tier`
- `/:slug/internal-dashboard/reports/campaigns`
- `/:slug/internal-dashboard/reports/failed-donations`
- `/:slug/internal-dashboard/reports/abandoned-carts`
- `/:slug/internal-dashboard/reports/recurring-deductions`
- `/:slug/internal-dashboard/reports/repeat-donors`
- `/:slug/internal-dashboard/reports/gifts`
- `/:slug/internal-dashboard/reports/project-donors`

كل بطاقة في الشبكة الحالية تربط بالمسار الموافق لها.

## التفاصيل التقنية
- استخدام `react-router-dom` للتنقل بين الأيقونة وصفحتها.
- جلب البيانات من الجداول الموجودة: `donors`, `donations`, `campaigns`, `tasks`, `recurring_donations`, `gifts`, `projects`.
- إن لم تكن بعض الجداول موجودة (مثل `gifts` أو `abandoned_carts`)، سننشئ migrations لإنشائها مع RLS مناسبة.
- إعادة استخدام `<UnifiedDateFilter />` يُحدِّث query param `?period=today|yesterday|week|...&from=&to=`.
- الإجراءات المنفذة تُجمع بـ aggregate query على `tasks` مفلترة بـ `metadata->>donor_id`.

## نطاق التنفيذ المقترح
بسبب الحجم الكبير، أقترح التنفيذ على مراحل:
- **المرحلة ١ (هذه الجلسة)**: المكونات المشتركة (`UnifiedDateFilter`, `DonorActionsCell`, `ReportPageShell`) + أول صفحتين كنموذج كامل: **المتبرعون حسب الفئة المالية** و**الحملات**، مع ربط الأيقونتين.
- **المرحلة ٢**: التبرعات الفاشلة + السلال المتروكة + المستقطعون.
- **المرحلة ٣**: المتبرعون المتكررون + الإهداءات + متبرعو المشاريع + ربط تحليل الذكاء الاصطناعي بـ `smart-task-dispatcher`.

هل أبدأ بالمرحلة ١ مباشرة، أم تريد تنفيذ جميع المراحل دفعة واحدة في رسائل متتابعة؟
